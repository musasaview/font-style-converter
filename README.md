# Font Style Converter

英数字を装飾 Unicode 文字に変換する、ブラウザだけで動くツールです。英字・数字の装飾や整形など102種類の結果を、入力しながら比較・コピーできます。元の35スタイルもすべて維持しています。

- 入力欄の直下に、装飾を外した文字列を自動表示
- カテゴリ別のコンパクトな一覧、1行の文字見本と全文ツールチップ
- 装飾を外した入力から変わらない結果は薄く表示し、チェックボックスで非表示にできます
- 入力欄への自動フォーカス、作者の X・GitHub リンク
- 大文字・小文字・反転、全角・半角、濁点追加
- 上付き・下付き、かっこ付き大文字、各種数字、下線・取り消し線、複合装飾、モールス・ASCII符号
- コピー失敗時の手動コピー
- デスクトップ・スマートフォン対応

入力内容は保存・送信しません。外部フォントや変換 API は使用しません。

## 開発

```sh
bun install
bun dev
# 3000番が使用中の場合
PORT=3012 bun dev
```

```sh
bun test
bun run typecheck
bun run build
```

`dist/` は静的ホスティングに配置できます。アセットは相対パスなのでサブディレクトリにも対応します。`bun start` は本番モードの Bun サーバーを起動します。

Bun・React 19・TypeScript・Tailwind CSS の既存構成を維持しています。文字変換には標準 API を使用し、全角・半角変換用の外部 Git 依存を廃止しました。

## 変換の仕様

- 全角・装飾済み英数字、互換文字を NFKC 正規化して変換します（例：Ａ → A、㍿ → 株式会社）。絵文字の複合シーケンスは保持します。
- 各結果は装飾を外した共通の文字列から自動変換します。変換結果で入力を書き換える操作はありません。
- 大文字専用・小文字専用のスタイルは、対応する側へ英字を揃えて変換します。両方に対応するスタイルは入力の大文字・小文字を維持します。
- 「装飾なし」は完全な逆変換ではありません。重複する囲み漢数字は漢字に戻します。ミックス文字・スモールキャップも解除します。ミックス文字が借用する他言語の文字も英字へ変換されるため、完全な逆変換ではありません。
- 全角・半角は英数字・記号・空白と対応するカタカナが対象です。
- 濁点は文字・数字・記号・絵文字に追加でき、重ね付けも可能です。空白・改行は保持し、複合絵文字は分断しません。
- 見た目・読み上げ・文字数制限は貼り付け先によって異なります。
- `Intl.Segmenter` を備えるモダンブラウザ向けです。

## 追加スタイルの補足

- 上付き・下付きには専用字形のない英字があります。その文字は保持します。
- ギリシャ文字風・キリル文字風・点字風は見た目の置換です。翻訳や正式な点字表記ではありません。
- 数字スタイルは1桁ずつ置換します。たとえばローマ数字の `12` は `ⅠⅡ` であり、数値の十二を表す `Ⅻ` にはしません。
- 上付き・下付き・追加の囲み文字・結合装飾などは入力時に解除できます。字形が重複するもの、逆順、Leet、符号化などは完全には復元できません。漢数字・大字を自動的に英数字へ戻すことはしません。
- 追加文字の範囲は [Unicode の文字表](https://unicode.org/Public/17.0.0/charts/) を参照しています。対応フォントのない文字は四角などで表示される場合があります。
