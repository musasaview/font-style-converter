# font style converter

文字を Unicode の別の字形に変換し、一覧で比較・コピーできる Web ツールです。英字の書体、囲み文字、数の表記、漢字の字形、組文字、点字などに対応しています。変換処理はブラウザ内で完結し、入力内容を保存・送信しません。

## 使い方

1. 左側の入力欄に、変換したい文字を入力・貼り付けます。
2. カテゴリ別のカードで結果を比較し、コピーアイコンを押します。「装飾なし」や変化のない結果もコピーできます。
3. 「変換されない文字種を隠す」は初期状態でオンです。すべての変換を比較したい場合はチェックを外します。

入力欄の直下には、装飾を外した文字列を表示します。絞り込みはこの文字列と各結果を比較し、未入力時も見本に適用します。各カードの最下部には名前と1行の文字見本があります。

結果見出しには表示件数（「装飾なし」を除く）と「カテゴリへ移動」があり、スクロール中も使えます。選択欄には表示中のカテゴリだけが並び、選択するとその見出しへ移動します。

自動コピーが使えない場合は、対象の全文を選択した手動コピー欄を表示します。閉じるボタンまたは Escape で閉じるとコピー元のボタンへ戻り、ボタンが非表示になっていれば入力欄へ戻ります。

入力欄は空で開始し、次の2行をプレースホルダーとして表示します。未入力時だけ、この文字列の変換結果を表示します。入力するとその内容に切り替わり、クリアすると見本に戻ります。空白や改行だけの入力も入力内容として扱います。

```text
ABCD abcd あいう
0123456789
```

## 対応する変換

現在は「装飾なし」を含め88種類です。既存・追加の区別を設けず、字形や用途で分類しています。

| 分類 | 主な変換 |
| --- | --- |
| 英字の書体 | セリフ・サンセリフの太字や斜体、筆記体、フラクトゥール、袋文字、等幅、スモールキャップ |
| 囲み英字 | 丸・四角・黒丸・黒四角・かっこ |
| 他文字の字形 | ギリシャ文字風、キリル文字風、ルーン文字、ハングル風 |
| 上付き・下付き | 上付き英数字・大文字、下付き英数字・数字 |
| 数字 | 囲み・装飾数字、漢数字・大字、ローマ数字、数値としての漢数字・ローマ数字・英語、算木、各国の数字 |
| 漢字・かな | 旧字体、康熙部首、丸囲み漢数字、四角囲み漢字、組文字・単位記号、組文字の上段・下段読み |
| 記号 | トランプ、麻雀、サイコロ、リサイクル記号 |
| 点字・符号 | かな・英数字の点字、英数字のモールス符号 |
| 反転・整形 | 逆さまの字形、上下逆さま、逆順、Leet、大文字・小文字、全角・半角、濁点 |

## 変換の仕様と制約

- 入力の装飾を外した共通の文字列から、すべての結果を変換します。カードの変換を順番に重ねる方式ではありません。
- 全角・互換文字は NFKC 正規化します（例：`Ａ → A`、`㍿ → 株式会社`）。絵文字の複合シーケンスは保持します。
- 大文字専用・小文字専用のスタイルは、対応する側に英字を揃えます。両方に対応するスタイルは入力の大小文字を維持します。
- 専用字形や対応表のない文字は、そのまま残します。上付き・下付きや漢字の変換には対応範囲があります。
- 装飾の解除は完全な逆変換ではありません。他言語の文字を英字として復元する場合があり、字形が重複する置換、逆順、Leet、符号化などは元に戻せません。漢数字・大字を自動的に英数字へ戻すことはしません。
- 数字の字形は1桁ずつ置換します。「ローマ数字・大文字」の `12 → ⅠⅡ` と、「ローマ数字（数値）」の `12 → Ⅻ` は別の変換です。
- ギリシャ文字風・キリル文字風・ルーン文字・ハングル風は英字の字形置換です。翻訳や発音の転写ではありません。
- 全角・半角は英数字・記号・空白と対応するカタカナが対象です。濁点は記号・絵文字にも追加でき、空白・改行は保持します。
- モールス符号は英数字を含む行を変換します。変換できる英数字の字素がない行は、空白や記号を含めそのまま残します。
- 表示は端末・フォント・貼り付け先に依存します。外部フォントや変換 API は使用しません。`Intl.Segmenter` と `Map.groupBy` に対応するモダンブラウザが必要です。

### 数値の表記

文章中の非負整数を数値として変換します。全角数字は共通の正規化で対応し、先頭のゼロは取り除きます。`1,234` のような正しい3桁区切りも使えます。負数・小数・分数・指数表記・英数字の識別子（`item123` など）・不正なカンマ区切りは部分変換せず保持します。

| 変換 | 例・範囲 |
| --- | --- |
| 漢数字（数値） | `123 → 百二十三`。ゼロは「零」、十・百・千・万・億・兆を使用 |
| ローマ数字（数値） | `12 → Ⅻ`、`49 → ⅩⅬⅠⅩ`。1〜3999に対応し、1〜12は専用字形、それ以降は `ⅠⅤⅩⅬⅭⅮⅯ` による減算表記 |
| 英語（数値） | `123 → one hundred twenty-three`。米式の基数表記で `and` を入れず、十の位と一の位をハイフンで接続 |

漢数字・英語は先頭のゼロを除いて最大15桁（999,999,999,999,999）です。整数演算は `BigInt` を使います。範囲外は元の表記を保持します。

### 組文字

「組文字・単位記号」は `株式会社 → ㍿`、`カロリー → ㌍`、`kg → ㎏` のように複数文字を1文字にまとめます。U+3300〜3357、U+3371〜33DF、令和の `㋿` が対象です。[Unicode公式の互換分解](https://www.unicode.org/Public/UCD/latest/ucd/UnicodeData.txt)を共通入力と同じNFKCで正規化した表記から変換します。英字の大小を区別し、英単語の途中では置換しません。

「組文字・上段読み」は `カロ → ㌍`、`メー → ㍍`、「組文字・下段読み」は `リー → ㌍`、`トル → ㍍` のように、カタカナ組文字88文字の片方の段を読みとして使います。[Unicode公式文字表](https://www.unicode.org/charts/PDF/U3300.pdf)の字形から定めた固定表を使い、上下の配置は表示フォントに依存します。

どちらも左から長い一致を優先し、同じ読みの候補はコードポイント順で先の文字を採用します。未対応の文字は保持し、絵文字・結合文字・改行を分断しません。上段・下段はカタカナだけが対象です。装飾解除は従来の完全な互換分解を使い、`㌍` は「カロリー」に戻ります。

### 点字

ひらがな・カタカナ・英数字を文字単位で変換します。濁音・半濁音・拗音・一部の外来音、外字符・大文字符・数符に対応しています。

漢字の読み、分かち書き、助詞や長音の表記は自動判定しません。必要な読み・空白を入力してください。未対応の文字はそのまま残します。

文字表の参照元： [日本点字図書館の点字一覧表](https://www.nittento.or.jp/images/pdf/information/braille_lists.pdf)、[Unicode の文字表](https://unicode.org/Public/17.0.0/charts/)。絵文字や結合文字は [Unicode の字素境界仕様](https://www.unicode.org/reports/tr29/tr29-47.html#Grapheme_Cluster_Boundaries)に沿ってまとめて扱います。

## 開発

Bun・React 19・TypeScript・Tailwind CSS を使用しています。依存関係は `bun.lock` で管理します。

```sh
bun install --frozen-lockfile
bun run dev
```

開発サーバーは通常 `http://localhost:3000` で起動します。ポートを変更する場合：

```sh
PORT=3012 bun run dev
```

### 検証とビルド

```sh
bun test
bun run typecheck
bun run build
```

ビルドは `dist/` を再生成します。静的ホスティングに配置でき、アセットは相対パスです。`bun run start` はソースを使って本番モードの Bun サーバーを起動します。`dist/` のプレビューコマンドではありません。
